# V10 差分聚类任务：CVR

## 任务
休食商笔按"类目内 cvr P75 vs P25"切两组对照（控类目变量），找出**高组独有 / 高组明显多于低组**的写法模式，给商家"想提升 CVR，看标题 + 正文 + ASR 完整内容（ 该怎么写/做"的可执行指导。

## 输入文件（在 work 目录下）
- `data/v10_clusters/cvr_high.txt`（见文件实际行数）—— CVR 高组
- `data/v10_clusters/cvr_low.txt`（见文件实际行数）—— CVR 低组

行格式：`[note_id|类目|cvr=X|imp=Y] [字段]内容 | [字段]内容 | ...`

## 部位说明（重要）
**只看 CVR 物理负责的部位**：看标题 + 正文 + ASR 完整内容（人群锁定/解决方案/复购数据/品牌背书）

不要把无关字段的内容当结论（例：CTR1 池里有正文片段是为了上下文，但聚类结论只能来自封面档位+标题）

## 严格做法
1. **单独聚类高组**：归纳 8-15 个写法簇（标点结构、句式、人称、修辞、字段命中规律）
2. **单独聚类低组**：同样归纳低组簇
3. **差分对比**：
   - 高组占比 / 低组占比 > 2x → 候选"高组独有"
   - 低组占比 / 高组占比 > 2x → 候选"低组陷阱"
4. **每个候选簇产出**：
   - 簇名（人话，例："封面美学=高 + 标题压到 15 字内"）
   - 高 N vs 低 N + 差距 pp
   - 类目分布（标"跨类目通用 / 茶酒高度集中 / 养生食疗专属"）
   - 3 个高组代表案例（原标题/原 ASR/原商品名节选）
   - 1-2 个低组反例
   - 一句商家可执行建议
5. **必须标注**：
   - 信心等级（高 / 中 / 低）+ 理由（差距大小 / 跨类目程度 / 样本量）
   - 茶酒占比 >50% 的簇默认信心降一档
   - 样本 <5 条的簇不要列

## 产出
JSON 写入 `data/v10_clusters/cvr.diff.json`：
```json
{
  "metric_key": "cvr",
  "high_only_patterns": [
    {
      "cluster_name": "...",
      "high_n": N, "low_n": N, "diff_pp": N,
      "category_dist": "跨类目通用 / 茶酒集中 / ...",
      "confidence": "高/中/低",
      "confidence_reason": "...",
      "high_examples": ["...", "...", "..."],
      "low_contrast_examples": ["..."],
      "merchant_advice": "一句话可执行"
    }
  ],
  "low_only_patterns": [...同上结构...],
  "key_mechanism": "一句核心总结：CVR 高 vs 低 的本质差别是什么"
}
```

完后回复 markdown 总结：3-5 个最强发现 + 2 个反直觉发现 + 整体信心评估。
