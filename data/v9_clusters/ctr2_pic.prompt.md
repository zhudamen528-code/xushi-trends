# 任务：归纳「休食 · 图文笔记（CTR1 看封面+标题；正文文字承载信息） · 笔记→商品卡点击率」的内容方法

## 背景
- 你拿到 60 条休食类目下「笔记→商品卡点击率」表现优秀的笔记
- 该指标核心是看：看正文叙事是否种草、商品卡何时挂、用户是否被钩到去看商品
- 数据来源：近 60 天 fullchain，按该指标降序排序

## 你的任务
1. 把这 60 条笔记按「内容方法」聚类（不是按品类/品牌聚）
2. 归纳出 **4-5 个独立的方法**（必须有显著差异，不能重复）
3. 每个方法必须包含：
   - `method_name`: 12 字内方法名（emoji 开头）
   - `essence`: 30 字内核心定义（这个方法是什么）
   - `why_works`: 50 字内为什么这个方法能拉高该指标（数据驱动归纳，不是套路话）
   - `signals`: 3-5 条可执行的内容信号（如"封面用 X 元素""标题含 Y 句式""商品卡挂 Z 数量"），具体可抄
   - `applicable_category`: 适合品类清单（基于这批笔记的真实商品类目分布给）
   - `note_ids`: 归到该方法的笔记 ID 列表（≥5 条，按指标排序）
4. 最后给出 `cluster_rationale`: 100 字内说"为什么这样聚类，依据是什么"

## 输出格式
严格 JSON：
```json
{
  "methods": [
    {"method_name": "...", "essence": "...", "why_works": "...", "signals": ["...","..."], "applicable_category": ["..."], "note_ids": ["...","..."]}
  ],
  "cluster_rationale": "..."
}
```

## 红线
- 不许编标题/亮点：所有方法依据必须能从下面笔记里找到证据
- 不许预设方法（不要套"封面钩子/数字反差/痛点共鸣"这种现成标签）
- 必须从数据归纳：先看完 60 条找规律，再定方法名
- 至少 1 个方法要包含"反直觉发现"（如某种商品类型的特殊玩法）
- 视频池要关注 ASR 文本里的开头话术/节奏；图文池要关注正文段落结构
