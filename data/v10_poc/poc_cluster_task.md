# V10 PoC: 高低真诚度标题差分聚类

## 任务背景
休食笔记按类目内 sincerity P75 vs P25 切两组（控类目 + 实际曝光 ≥2000）：
- 高真诚度组：173 条标题
- 低真诚度组：129 条标题

## 目标
找出**高组有但低组没有 / 高组明显多于低组**的标题写法模式，给商家"想被算法判定为真诚分享，标题该怎么写"的可执行指导。

## 输入文件（在 work 目录下）
- `data/v10_poc/high_titles.txt` （173 条高真诚度标题）
- `data/v10_poc/low_titles.txt` （129 条低真诚度标题）

文件格式：每行 `[note_id|类目|imp=XXX] 标题文本`

## 严格做法
1. **先单独聚类高组**：把 173 条标题归纳成 8-15 个写法簇（标点结构、句式、人称、修辞、关键词族）
2. **单独聚类低组**：同样归纳低组的写法簇
3. **差分对比**：
   - 哪些写法簇**只在高组出现 / 高组占比远超低组**（>2x）→ 候选"高真诚度写法"
   - 哪些写法簇**只在低组出现 / 低组占比远超高组**（>2x）→ 候选"低真诚度陷阱"
4. **每个候选簇给**：
   - 簇名（人话，比如"我帮你/我教你 + 反常识结论"）
   - 高组命中数 vs 低组命中数（差距 +N pp）
   - 3 个高组代表标题原文
   - 1-2 个低组**对照标题**（同类目但写法相反的）
   - 一句话商家可执行建议
5. **必须做的边界标注**：
   - 哪些簇是茶酒类目高度集中（疑似品类特性）
   - 哪些簇跨多个类目都成立（更可推广）
   - 样本量 <5 条的簇不要列出（噪声太大）

## 产出格式
JSON 文件 `data/v10_poc/v10_poc_clusters.json`：
```json
{
  "high_only_patterns": [
    {
      "cluster_name": "我帮你/我教你 + 反常识结论",
      "high_n": 22,
      "low_n": 3,
      "diff_pp": 19,
      "category_dist": "跨类目（美食测评/养生/展示均有）",
      "high_examples": ["泡红茶，用错水，等于白扔钱", "教你一招避免烫茶伤食道", "..."],
      "low_contrast_examples": ["快来抢！限时9.9元..."],
      "merchant_advice": "标题开头用'我/教你/带你' + 给出反常识结论，避免上来就讲产品"
    }
  ],
  "low_only_patterns": [...],
  "category_biased_warnings": [
    "'年份+产地'类簇 87% 来自茶酒类目，非茶酒商家慎用"
  ],
  "confidence_summary": "找到 N 个高信心模式（差距>15pp且跨类目）+ M 个中信心 + K 个低信心"
}
```

## 输出
写完 JSON 后回复一段 markdown：列出 3-5 个最强发现 + 1-2 个反直觉发现 + 整体信心评估。
